# Springy Browser

Springy Browser is a lightweight, Chromium‑based desktop web browser with vertical tab support, a modern address bar, and custom Spring icon! 🌱🚀

---

## 🧾 Features

- Vertical tabs on the left  
- Clickable + button to open new tabs  
- Address bar — type any URL and press Enter  
- Works with videos and modern websites  
- Custom Spring icon and installable Windows app  

---

## 📦 Download & Install

Release installers will be attached on the **Releases** page.  
Once a release is published:

1. Download `Springy Browser Setup.exe`  
2. Run the installer  
3. Launch Springy Browser from your Start menu or desktop
